# Main 315 – launch readiness checkpoint

Main 303–315 hardens NackaSidan for public use.

## Completed
- current Stockholm-local update date in the masthead instead of a stale hard-coded issue range
- skip link and a stable main-content target
- visible keyboard focus and reduced-motion support
- baseline browser security headers
- web app manifest
- public About page with an explicit editorial promise
- About page exposed in footer and sitemap
- accessibility statement exposed publicly and indexed in the sitemap

## Editorial standard
NackaSidan must not present invented popularity metrics, sources, certainty or freshness. Editorial selections should be labelled as selections. Facts, analysis and uncertainty should remain distinguishable.

## Release gate
Before calling a deployment production-ready, verify the homepage, article pages, navigation, mobile layout, live-news failure state, forms, 404 page, sitemap, robots policy and keyboard navigation on the deployed URL.
