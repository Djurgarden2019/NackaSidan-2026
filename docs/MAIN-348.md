# Main 348 – incident guidance in driftstatus

Main 348 brings the incident runbook into the live operational interface.

## Changes
- adds a prominent “Vad gör vi nu?” section to `/driftstatus`
- recommends the next action based on deployment provenance and current health status
- shows the incident sequence directly in the UI
- links the full incident runbook from the drift tools navigation
- updates the driftstatus checkpoint label to Main 348

## Why
Operators should not need to remember or search for the incident workflow when something is wrong. The drift page now turns the current state into an immediate, actionable next step.
