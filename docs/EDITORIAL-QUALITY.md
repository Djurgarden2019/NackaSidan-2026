# Redaktionella kvalitetsregler

- Prioritera uppgifter publicerade eller uppdaterade nyligen.
- Ange källa på varje redaktionell nyhet.
- Märk partikällor som partikällor och behandla dem inte som neutrala nyhetskällor.
- Skilj verifierade fakta från analys.
- Lägg till varför nyheten spelar roll för läsaren.
- Undvik dubblerade artiklar om samma händelse.
- Uppdatera eller flytta ned gamla nyheter när ny information tillkommer.
