# Main 353 – release verification on driftstatus

Main 353 brings the machine-readable release verdict into the human operations view.

## Changes
- adds a prominent VERIFIED / BEVAKA / FAILED release card to `/driftstatus`
- links directly to `/api/release-verification`
- links the release verification checklist from the drift tools
- updates the driftstatus release marker to Main 353
- explains how the release verdict relates to provenance and health

## Why
Main 352 created one machine-readable release signal. Main 353 gives operators the same verdict at a glance and keeps human and automated release verification aligned.
